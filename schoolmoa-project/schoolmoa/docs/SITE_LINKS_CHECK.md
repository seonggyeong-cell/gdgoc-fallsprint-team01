# 사이트 모음 주소 확인표
`src/data/sites.ts`의 주소를 직접 눌러 확인하기 위한 표입니다. 확인한 줄은 `☐`를 `☑`로 바꾸고, **열리지 않거나 엉뚱한 화면이면 `sites.ts`에서 그 줄만 고치거나 `entries`를 지우세요.** (`entries`가 없으면 카드는 자동으로 사이트 메인으로 연결됩니다.)
- **확인됨**: 이 프로젝트를 조사할 때 검색 결과에서 해당 사이트 주소가 실제로 나타난 경우
- **미확인**: 사이트 구조를 바탕으로 넣은 주소라 직접 열어 보기 전에는 맞는지 알 수 없는 경우 (구체 화면·검색 주소 대부분)
- 사이트 개편으로 주소가 바뀔 수 있어 `확인됨`도 발표 전에 한 번 더 눌러 보는 것이 좋습니다.
