# 변경 내역 (원본 디자인 템플릿 → 스쿨모아 프로젝트 구조)

## 구조 변경
- `components/` 하나에 있던 파일을 역할별 `features/*` 폴더로 분리, 상수는 `config/constants.ts`로 통합
- `App.tsx`의 상태·필터 로직을 hook(`useNotices`, `useNoticeFilters`, `useBookmarks`, `AuthContext`)으로 분리 → `App.tsx`는 화면 조립만 담당
- TypeScript `strict` 활성화, `@/` import 별칭 추가, AI Studio 전용 의존성(express, dotenv, @google/genai, motion 등) 제거

## 요청 반영
| 요청 | 반영 |
|---|---|
| 근로장학·돈 버는 방법, 인턴·취업 | 카테고리 **근로·알바**, **인턴·취업** 신설 (잡코리아·사람인·링커리어·알바몬 출처) |
| 봉사·해커톤 등 활동 확대 | **공모전·해커톤**, **봉사·대외활동**(봉사/서포터즈/동아리/해외·교환/멘토링) |
| 인하대 공지 | 카테고리 **인하대 공지** + `inhaNoticeService.ts` (연동 지점 준비, 현재 샘플) |
| 학년별 분류 제외 | 학년 필터·학년 데이터·학점/소득 자격 진단 제거 |
| 외부 링크 연결 | 모든 공고에 `officialUrl` 필수, 카드/표/상세에서 원문 이동, 출처 사이트 필터 |
| 정렬 | 마감일 빠른순 / 최신순 / 인기순 / 지원규모순 |
| due date 명확 표기 | 카드·표·상세에 `2026.11.05 (목)` 형식 + D-Day 배지, 상세는 큰 글씨로 표시 |
| 소셜 로그인 | 구글(팝업)·네이버(리다이렉트) + 개발용 체험 로그인 |
| 학과·진로 입력 → 추천 | 첫 로그인 시 입력창, `recommend.ts`가 점수·추천 이유 계산 |
| 즐겨찾기 | 로그인 사용자별 저장(로그아웃·다른 계정과 분리), 비로그인 시 로그인 창 |
| 캘린더 | 로그인 시 기본으로 **내 보관함 공고의 마감일**만 표시 (전체 공고 보기 전환 가능) |

## 추가한 운영 기능
- **마감된 공고 자동 숨김** + "마감된 공고 포함" 토글 (목록이 낡지 않게)
- **출처 사이트 필터** (인하대/잡코리아/… 별로 모아보기)
- **공고 제보** (로그인 사용자가 링크와 함께 등록; 제보분만 저장하여 기본 데이터 갱신과 충돌 없음)
- **개인정보 수집 안내** 문구 (학과·진로 수집에 대한 고지)
- 마감일 `.ics` 다운로드, 보관함 지원규모 합계에서 미선정 공고 제외

## 고친 문제
- 오늘 날짜가 `2026-09-30`으로 코드에 박혀 있던 부분 → `getToday()` (환경변수로 고정도 가능)
- `.ics` 종일 일정의 종료일이 시작일과 같아 일정이 어긋나던 문제 수정
- 공고 전체를 localStorage에 저장해 샘플 데이터 수정이 반영되지 않던 구조 → 제보 공고만 저장
- 샘플 마감일이 모두 지나 빈 화면이 되던 문제 → 오늘 기준 상대 날짜로 생성
